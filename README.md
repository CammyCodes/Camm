# 🤖 CammBot — We build the robot. You get on with the job. ✨

Welcome to **CammBot**! A friendly, high-performance landing page designed to rescue small businesses (trades, property management, services, and online sellers) from drowning in boring administrative overhead! 🌊💼

Say goodbye to manual invoices, drafting emails, optimizing listings, and chasing reviews. CammBot handles it all in the background while you focus on the real work. 🚀

---

## 🌟 Features

### 📱 1. "Watch CammBot Do the Boring Stuff" Showcase (`#showcase`)
Positioned right under the hero, this is CammBot's main control center. It displays an interactive smartphone frame showcasing CammBot doing real work:
*   📅 **Daily Catch-Up**: Timed digests of enquiries, bookings, and alerts.
*   📸 **List & Optimise**: Creating SEO-ready listings for eBay, Etsy, or Amazon from a single photo.
*   💰 **Instant Quote**: Auto-chasing client details and returning instant quote sheets.
*   💸 **Chase the Money**: Automatic friendly invoice reminders and payment tracking.
*   ⭐ **Reviews on Autopilot**: Auto-sending Google Review links and private-logging low scores.
*Features standard play/pause toggles, active progress indicators, replay loops, and full keyboard-operable accessibility.*

### 📜 2. GSAP Scrollytelling (`#see-it-work`)
A high-end scrollytelling showcase representing CammBot app modules. As the user scrolls on desktop, the left column transitions through four visual examples, while the right phone frame stays pinned in the viewport using `gsap.matchMedia()` for smooth layout responsiveness.

---

## 🛠️ Tech Stack

*   **Core**: Next.js 16 (Turbopack) & React 19 🚀
*   **Typing**: TypeScript 🛡️
*   **Styling**: Tailwind CSS & Vanilla CSS Variables 🎨
*   **Animations**: GSAP (GreenSock) + ScrollTrigger & Framer Motion 💫
*   **Smooth Scroll**: Lenis Scroll integration 🌊

---

## 🚀 Getting Started

### 1. Install Dependencies 📦
```bash
npm install
```

### 2. Run the Development Server 💻
```bash
npm run dev
```
Open [http://localhost:3000](http://localhost:3000) to view CammBot in action!

### 3. Production Build 🏗️
```bash
npm run build
```
